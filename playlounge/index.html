Play Lounge

Multiplayer board games. No accounts. No chat.

Play Lounge is a multiplayer board game platform for the web and Android. There are no accounts, no profiles, and no communication features — sessions are anonymous and data lives only while the app is open. PEGI 3 / Everyone, COPPA-compliant.

Web Android Free All ages
Play on the web Get it on Google Play
Features

Built around what matters.

  • No accounts

    No sign-up, no email, no profile. Pick a name and play.

  • Session-only data

    Game state is held only while you’re in a session.

  • Safe for all ages

    PEGI 3 / Everyone rated. COPPA-compliant for children’s privacy.

  • No communication features

    No chat, no voice, no DMs. The game is the interaction.

  • Cross-platform

    Web and Android, designed to feel native on both.

  • Free, ad-supported

    AdMob and AdSense fund the service. No analytics SDKs.
